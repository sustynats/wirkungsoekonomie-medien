# Medien der Wirkungsökonomie

Dieses Repository ist für ausdrücklich zur Veröffentlichung freigegebene Medien der Wirkungsökonomie vorgesehen.

Private Rohdaten, Zugangsdaten, unveröffentlichte Texte, Entwürfe und vertrauliche Aufträge gehören nicht hierher. Bestehende historische Medienlinks bleiben erhalten.
